# 宇宙探査アプリ (Space Travel Idle)

スマホから離れた時間を宇宙船が宇宙を探索する時間に変える、完全オフライン・放置型の天体探索Androidアプリ。

## 特徴

- **完全オフライン**: インターネット通信権限（`INTERNET`）なし、広告なし、外部追跡なし
- **通知なし**: ユーザーの時間を奪わない設計
- **100種の天体図鑑**: 実在の天体（小天体、小惑星、惑星、恒星、星雲、ブラックホール等）と架空の謎の探査機
- **船体カスタマイズ**: 獲得したクレジットで船体スキン（8種）、エンジン炎（4種）、窓ライト（3種）を解放
- **ダーク/ライト・UIサイズ切替**: 視認性に合わせた1.0x / 1.5x / 2.0xのスケーリング対応
- **時空の乱れ（時計巻き戻し）検知**: 不正な時計巻き戻しを検知し、ペナルティを付与

## デバッグ用メニュー（試作版限定）

設定画面（⚙️）に【デバッグ】時間加速メニューを搭載しています（※正式リリース時に削除予定）。
- +30分 / +2時間 / +6時間 / +12時間 / +24時間 / +48時間の時間早送り
- 25時間の時計巻き戻しテスト（時空の乱れ検知ロジックの動作検証用）
- 時間オフセットのリセット

## 技術構成

- **OS / 言語**: Android (Kotlin)
- **UI**: Jetpack Compose, Material 3
- **状態管理**: ViewModel + StateFlow
- **データ永続化**: SQLite (AppDatabaseHelper) + SharedPreferences
- **対応SDK**: minSdk 28, targetSdk 36, compileSdk 36
